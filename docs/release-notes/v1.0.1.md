## Fresh install required

The SkunkCrafts Updater URL shipped with 1.0.0 pointed at a repository that
no longer exists, so 1.0.0 installations cannot receive updates.

**If you installed 1.0.0 (or earlier): download this release ZIP and install
it manually, replacing the old plugin folder.** From 1.0.1 on, the SkunkCrafts
Updater picks up new versions automatically.

Your API keys (macOS Keychain), custom VRPs, airspace override and flight logs
are stored outside the plugin folder and are kept. Inside the plugin folder,
carry over `data/settings.json` (your settings) and `Resources/models/`
(downloaded local models, avoids re-downloading ~2 GB).
